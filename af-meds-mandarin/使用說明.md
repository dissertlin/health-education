# 國語語音衛教頁面｜使用說明

## 目前版本

- 頁首與每一章都使用完全相同的播放方式。
- 按醒目的深綠色「🔊 按這裡聽」按鈕開始；播放中同一個按鈕會變成「⏸ 暫停」。
- 暫停後，同一個按鈕會變成「▶ 繼續」。
- 每一段下方左邊都有「⏸ 暫停」按鈕；暫停後會變成「▶ 繼續」。
- 每一段下方右邊都有「↻ 從頭重播」按鈕。
- 使用手機／瀏覽器內建的台灣華語聲音，以自然、清楚的速度播放。

## 正式上線前

1. 用 iPhone 與 Android 各測試一次國語重點版和任一章節。
2. 用新版 `index.html` 取代原網站 `/health-education/af-meds/` 的頁面。

只要網址仍是 `https://dissertlin.github.io/health-education/af-meds/`，目前紙本上的 QR code 不必重印。
